# Golden Assets

This directory contains the lightweight reviewed-golden layer for the current Phase 1 MVP.

Current scope:

- only official `openai.com` English-Korean page-pair examples are active
- Developer-document examples have been removed from the current golden set and can be reintroduced later as Phase 2 assets
- the current approved subset is paragraph-level only

Files are preserved for the full word/sentence/paragraph shape:

- `words.json`: currently empty placeholder
- `sentences.json`: currently empty placeholder
- `paragraphs.json`: current approved reviewed-golden records from the official Phase 1 pair

## Role In The Repository

- `reference_ko`: official Korean page text used as the Phase 1 pair-evaluation baseline
- `candidate_ko`: first-pass Korean output generated by `gpt-5.5`
- `improved_candidate_ko`: rewrite output generated by `gpt-5.5`
- `reviewed_golden_ko`: maintainer-approved Korean target used for lightweight golden checks

The project is not trying to prove that community output is better than the official Korean page. The purpose is to show that candidates can be evaluated against an official reference, reviewed by a human, and promoted into a small regression target only after approval.

## Record Fields

Current approved paragraph records keep:

- `source_en`
- `reference_ko`
- `candidate_ko` or `bad_ko` as the contrastive/non-approved Korean example
- `contrastive_ko`
- `improved_ko`
- `reviewed_golden_ko`
- `notes`
- `tags`
- `status`
- `target_role`
- `review_status`
- `provenance`

Field meaning:

- `source_en` is the official English source block.
- `reference_ko` is the official Korean reference block from the page pair.
- `contrastive_ko` is a comparison example. It is not a golden target.
- `reviewed_golden_ko` is the maintainer-approved Korean target for golden evaluation.
- `improved_ko` is kept as a compatibility alias for `reviewed_golden_ko`.
- `bad_ko` is kept only for compatibility with older examples and should not be read as a judgment on the official Korean page.
- `status = approved_reviewed_golden` means the item is part of the current approved subset.

## Approved Source

The current approved records come from [reviews/phase1_pair_review.md](../../reviews/phase1_pair_review.md).

Each promoted record in `paragraphs.json` includes provenance back to:

- the review worksheet
- the pair slug
- the source block id
- the maintainer decision

## Evaluation Selection

[run_golden_eval.py](../../run_golden_eval.py) supports `words`, `sentences`, and `paragraphs`, but only `paragraphs` currently contains active approved records.

For the current MVP, use:

```powershell
python -X utf8 run_golden_eval.py --golden-set paragraphs --skip-backtranslation
```

`words.json` and `sentences.json` are intentionally empty until official page-pair word/sentence examples are curated.
